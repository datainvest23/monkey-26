Method, not magic

One engine, any valid universe.

01 / DEFINE

Set the eligible universe

Presets and filters create a transparent list of eligible securities. The experiment will not run with fewer than 25 candidates.

02 / REDEAL

Shuffle, then deal 25

Every throw begins with a fresh cryptographic Fisher–Yates shuffle. The first 25 securities become the hidden wall.

03 / SELECT

Hit one unbiased cell

Rejection sampling makes all 25 cells exactly equally likely. Combined with the fresh deal, every eligible security has probability 1/N.

04 / VERIFY

Analyse the outcomes

Entropy, expected coverage and a dynamic N-category chi-square test measure whether the observed sample remains consistent with equal selection.

Statistical interpretation. The chi-square approximation becomes more informative as expected observations per security increase. For a 360-security universe, early results are exploratory; the interface marks when the sample reaches the conventional five-observations-per-category threshold. This is an educational experiment, not investment advice.
